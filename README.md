# India-Energy-Data-Analysis
Python-based analysis of India's energy capacity ,electricity generation and power sector emissions from 2019 to 2024
# India Energy Data Analysis (2019–2024)
## Project Overview
  This project focuses on analyzing India's energy sector data from 2019 to 2024 using Python. The analysis covers electricity generation, energy capacity, and    power sector emissions.
## Project Objectives
  - Analyze changes in energy generation and capacity over the years.
  -Compare different energy sources, including renewable and fossil fuels.
  -Study power sector emissions.
  -Examine year-over-year (YoY) changes.
  -Identify important trends using data visualization.
## Tools and Libraries Used
  -Python
  -Jupyter Notebook
  -Pandas
  -NumPy
  -Matplotlib
  -Seaborn
# Dataset Description
  The dataset contains energy-related information, including country, state, year, category, subcategory, energy source, unit, value, and year-over-year changes.
  
# The three main categories are:
  1. Capacity
  2. Electricity Generation
  3. Power Sector Emissions
# Data Analysis and Visualization
  The project includes 10 visualizations, including line charts, bar charts, scatter plots, histograms, heatmaps, box plots, and violin plots.
